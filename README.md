# Amirnet Helper

## About the project

I was in a rush: I had only 2 days left before the exam and I wanted something fast to practice with, so I built this simple site for practicing the Amirnet exam (academic English level).

The entire project was written by Claude.

## Structure tree

```
Amirnet/
├── index.html      <- the page (menu + quiz + result areas), loads all scripts
├── style.css       <- design
├── app.js          <- all the logic
│
├── questions.js    <- old pool: SENTENCES (25) + RESTATEMENTS (12)
├── sentences2.js   <- SENTENCES2 (65)
├── sentences3.js   <- SENTENCES3 (65) + SENTENCES_ALL (195)
├── tests1.js       <- Q() helper, TESTS, exams 1-5
├── tests2.js       <- exams 6-10
├── tests3.js       <- EXTRA: w1, w2, r2 for each exam
├── tests4.js       <- LONG: long restatements, builds r4 / r5
├── reading.js      <- READING: 12 passages, links 10 of them to the exams
│
├── vocab.js        <- VOCAB: English -> Hebrew words
├── vocab2.js       <- more words for VOCAB
├── he.js           <- HE: Hebrew translations of the Restatements
│
├── CLAUDE.md       <- project notes for Claude
└── README.md       <- this file
```

The files are loaded by `index.html` in this exact order (everything is global, so the order matters):

`vocab` -> `vocab2` -> `questions` -> `tests1` -> `tests2` -> `tests3` -> `tests4` -> `sentences2` -> `sentences3` -> `he` -> `reading` -> `app`

### Explanation for each file

| File | What it does |

| `style.css` | All the design: light/dark mode, numbered reading passage, translation boxes, correct/wrong colors. |
| `app.js` | All the logic: building the exams (`buildSteps`), shuffling (`prepare`), showing a question and revealing the answer (`renderQuestion`), the translations after an answer, the numbered reading passage (`layoutPassage`), the score (`estimateScore`, `levelNote`), saving best scores in the browser, and the endless game. |
| `questions.js` | The old pool, used only for random practice: `SENTENCES` (25 sentence completions) and `RESTATEMENTS` (12 restatements). `PASSAGES` in this file is old and **not used** any more (replaced by `reading.js`). |
| `sentences2.js` | `SENTENCES2`: 65 more sentence completions (35 with one blank, 30 with two blanks). |
| `sentences3.js` | `SENTENCES3`: 65 more sentence completions. Also builds `SENTENCES_ALL` = `SENTENCES` + the `s` of all 10 exams + `SENTENCES2` + `SENTENCES3` (195 questions) - the pool for random practice and the endless game. |
| `tests1.js` | Defines `Q()` and `TESTS`. Exams 1-5: each has `s` (4 sentence completions), `p` (the reading passage, filled later) and `r` (3 short restatements). |
| `tests2.js` | Exams 6-10, same structure as `tests1.js`. |
| `tests3.js` | `EXTRA`: for every exam, `w1` and `w2` (4 word completions each) and `r2` (3 more short restatements). Merged into `TESTS` by index. |

| `vocab2.js` | More words added to `VOCAB` (for the questions in `sentences2.js` / `sentences3.js`). |
| `he.js` | `HE`: full Hebrew translations for the Restatements questions (the original sentence + the 4 options). Connected to the questions as the `h` field. |

## How to install

No installation needed. There are no dependencies, no build step and no server - just download/copy the project folder to your computer.

## How to run

Just open the `index.html` file in your browser (double click on it).

### How to use

1. **Pick what to practice** from the menu: an endless game, one of the 10 exams, or random practice.
2. **Answer by clicking an option.** The correct answer is hidden until you click. After the click you see right/wrong, an explanation in Hebrew and the Hebrew translation of the options.
3. **Exams and random practice:** the `Next Part` button opens only after you answer every question in the chapter. The last chapter shows `Finish`, and then your estimated score (50-150). `Menu` takes you back at any time.
4. **Endless game:** answer, read the explanation, click `Continue ▶` (or press `Enter` / `Space`). You can use the keyboard to answer: `A-D` or `1-4`. Click `סיים משחק` when you want to stop.
5. Your best results are remembered by the browser (see "What inside"). If you open the file in a different browser, you start with no saved scores.

## What inside

### Fixed exams
- **10 fixed exams**, each with 6 chapters in a fixed order (23 questions):
  1. Word Completions - 4 questions
  2. Word Completions - 4 questions
  3. Reading Comprehension - one passage + 5 questions
  4. Restatements - 3 questions (2 short + 1 long)
  5. Restatements - 3 questions (2 long + 1 short)
  6. Sentence Completions - 4 questions (some with two blanks)
- The correct answer is **not revealed until you click an answer**. After clicking you see right/wrong marking and an explanation in Hebrew.
- In the completion chapters, a **Hebrew translation of all four options** is shown after you answer.
- In the Restatements chapters, a **full Hebrew translation of the original sentence and every option** is shown, with the English word/phrase in parentheses.
- At the end you get an **estimated Amirnet score (50-150)**, the number of correct answers and a level note. Your best score for each exam is saved in the browser.

### Random practice
- **Random full exam** - 6 chapters built randomly from the entire question pool.
- **Single chapter** - random Sentence Completions, Reading Comprehension or Restatements.

### Endless game
Three modes: mixed, Sentence Completions only, and Restatements only.
- One random question at a time, with explanation/translation, then `Continue`.
- No repeats until the whole pool was seen.
- Sticky bar with SCORE, STREAK, CORRECT and BEST. 10 points per correct answer + 2 for each correct answer in a row (up to +10). A mistake resets the streak.
- Keyboard: `A-D` / `1-4` to choose an answer, `Enter` / `Space` to continue.
- Best score for each mode is saved in the browser.

### More
- Hebrew (RTL) interface with English (LTR) exam content.
- Light and dark mode (follows your system).
- Works fully offline.

## For The Future

All the content is plain JavaScript data files, so everything can be changed by editing them in any text editor and refreshing the page. There is no build step.

**After every change:** refresh the page and press `F12` -> Console. A typo shows up there as a red error (a broken file usually means the menu does not load at all).

### Question format
A question is written as `Q(question, explanation, correct, wrong1, wrong2, wrong3)`. **The correct answer is always first** - the site shuffles the order every time it is shown. `Q` is defined at the top of `tests1.js`.

- A question with **two blanks**: write each option as `"word1 ... word2"` (with spaces around the three dots).
- A reading question can contain `{L:word}` - it is replaced by the line number where `word` appears in the passage (the word must appear in the text).

### Where each type of question lives

| I want to add / change... | Where |
|---|---|
| Sentence Completions in a fixed exam (chapter 6) | `s: [...]` of that exam in `tests1.js` / `tests2.js` (keep 4) |
| Word Completions in a fixed exam (chapters 1-2) | `w1` / `w2` of that exam in `EXTRA` (`tests3.js`) (keep 4 each) |
| Short restatements in a fixed exam | `r` in `tests1.js` / `tests2.js`, and `r2` in `tests3.js` |
| Long restatements in a fixed exam | `LONG[exam]` in `tests4.js` (3 per exam) |
| The reading passage of a fixed exam | the matching item in `READING` (`reading.js`) |
| More Sentence Completions for random practice and the endless game only | add to `SENTENCES2` / `SENTENCES3`, or to `SENTENCES` in `questions.js` |
| More restatements for random practice and the endless game only | `RESTATEMENTS` in `questions.js` (also needs a translation, see below) |

Which pool uses what:
- **Endless game** - `SENTENCES_ALL` + all restatements (`RESTATEMENTS`, `r`, `r2`, `LONG`). It has no word completions.
- **Random full exam** - word completions from all the exams (`w1`, `w2`), a random passage from `READING`, restatements from all the pools, and 4 questions from `SENTENCES_ALL`.

### Add / remove / change questions
- **Add:** add a `Q(...)` line to the right array (see the table). To change a question, just edit its line. To remove, delete its line.
- **Word / sentence completion:** every word that appears as an option (**including the wrong ones**) must exist in `VOCAB`, otherwise it is shown without a Hebrew translation (see "Vocabulary").
- **Restatement:** needs a Hebrew translation in `he.js`: 5 strings in the **original** order (before shuffling) - `[original sentence, correct, wrong1, wrong2, wrong3]`. The translations are connected **by position**:
  - `RESTATEMENTS[j]` <-> `HE.base[j]`
  - `TESTS[i].r[j]` <-> `HE.r[i][j]`
  - `TESTS[i].r2[j]` <-> `HE.r2[i][j]`
  - `LONG[i][j]` <-> `HE.long[i][j]`

  So if you add or delete a restatement, add or delete the translation at the same position, otherwise every translation after it shifts to the wrong question. Write the English word in parentheses inside the Hebrew so it is clear which word is translated.
- **Reading passage:** add an item to `READING` in `reading.js`: `{ text: [paragraph, ...], qs: [Q(...) x5] }` (3-4 paragraphs, 5 questions in the usual types: title, first paragraph, purpose of the second paragraph, word in a line, inference from the last paragraph). A `title` field is optional and is not displayed. Items 0-9 belong to the exams (`READING.slice(0, 10)` at the bottom of the file); extra items are used only in random practice.

### Add or remove a whole exam (exam 11)
Everything is connected **by index**, so the new exam must be at the same position in every list:
1. `tests2.js` (or a new block): `TESTS.push({ name: "מבחן 11", s: [...4 Q], r: [...3 Q] })`
2. `tests3.js`: add an item to the end of `EXTRA` with `w1`, `w2`, `r2`.
3. `tests4.js`: add 3 long restatements to the end of `LONG`.
4. `he.js`: add an item at the end of each of `HE.r`, `HE.r2` and `HE.long` (translations).
5. `reading.js`: add a passage and change `READING.slice(0, 10)` to `slice(0, 11)` - and make sure the passage at index 10 is the one meant for exam 11 (today index 10 and 11 are random-practice-only passages, so move or add accordingly).
6. `index.html`: change the title "10 מבחנים מלאים" (the exam buttons are created automatically from `TESTS`).

To remove an exam, remove its item from `TESTS`, `EXTRA`, `LONG`, `HE.r`, `HE.r2`, `HE.long` (same index), and update the passage link.

### Vocabulary
`vocab.js` and `vocab2.js` hold one long text of `english:hebrew` pairs separated by `|`:

```
abandon:לנטוש|abolish:לבטל|abrupt:פתאומי, חד
```

- To add a word, put `|newword:תרגום` before the closing backtick in `vocab2.js` (the file for new words).
- To fix a translation, edit the pair. If a word appears in both files, the later one (`vocab2.js`) wins.
- The word must be written exactly like the option in the question (lowercase, same spelling). For two-blank options each word is translated separately.

### Difficulty
- Difficulty is determined by the questions and the wrong options: use harder words and closer distractors to make it harder, simpler ones to make it easier.
- Make sure the wrong options are really wrong (no second correct answer).
- In Restatements, vary the length of the correct answer - it should not always be the longest.
- The score formula is `estimateScore` in `app.js` (`round(50 + 100 * right / total)`) and the level notes are in `levelNote()` (thresholds 134 / 120 / 100). It is a linear approximation, not the official conversion.
- Endless game scoring: `BASE_POINTS` (10), `STREAK_BONUS` (2) and `MAX_BONUS_STEPS` (5) at the top of the "Endless game" block in `app.js`.
- The reading passage line width (characters per line) is `LINE_WIDTH` in `app.js`.

### Saved scores
Scores are saved in the browser (`localStorage`): `amirnetScores2` for the exams and `amirnetEndlessBest` for the endless game. Exams are scored out of 23 (written in `app.js`, in `renderTestButtons`, together with the "6 chapters, 23 questions" text). If you change the number of questions in an exam, update those and also change the key name `amirnetScores2`, so old saved scores will not get mixed up. To reset all scores, clear the site data of the page in the browser.
